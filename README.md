# EchoSearch VS Code Extension

EchoSearch adds up to 10 independent search boxes in a sidebar view.

## Features

- 10 parallel search boxes.
- Works on opened files (active visible editors), similar to Ctrl+F highlight behavior.
- Per-search custom highlight color.
- Plain text mode and regex mode.
- Case-sensitive and whole-word matching.

## Run

```bash
npm install
npm run compile
```

Then press `F5` in VS Code to launch an Extension Development Host.
